Yses.txt
M1N1
============
本仕様書はLicense.txt M1N1に従うものとします。

本仕様書では、1オペコードプログラミング言語であるYsesについてを纏めています。


基本
------------
Ysesでは、全ての命令が1文字の記号で定義されます。
  使用する記号の一覧、及び記号の定義については、項目「命令」「0オペランドオペコード」「1オペランドオペコード」「2オペランドオペコード」及び各命令項目を参照してください。

Ysesは、AI生成のコストが低いプログラミング言語について考える為に作成したプログラミング言語です。
比較的人間にも書きやすい言語の可能性もあります。

M1N1版では、利用可能な「メモリ」はスタックに限定されます。


レジスタ
------------
Ysesでは、以下のレジスタを使用する事が出来ます。但し、以下に示すレジスタは全て汎用レジスタ扱いです。
	A
	B
	C
	D
	E
	H
	L
	N
	K
	P
	Q
	R

また、システムレジスタとして以下のレジスタが定義されています。
	PC
	SP
	F


命令
------------
命令は3つの種類が存在します。
	0オペランドオペコード
	1オペランドオペコード
	2オペランドオペコード


0オペランドオペコード
------------
0オペランドオペコードには以下の2種類の命令が存在します。
	!           :=: 未定義
	^           :=: ランドマーク


1オペランドオペコード
------------
1オペランドオペコードには以下の8種類の命令が存在します。
	#A          :=: レジスタクリア
	$A          :=: 整数値入力 (Stdin)
	'A          :=: 文字入力 (Stdin)
	&A          :=: 文字出力 (Stdout)
	/A          :=: インクリメント
	\A          :=: デクリメント
	*A          :=: プッシュ
	%A          :=: ポップ


2オペランドオペコード
------------
2オペランドオペコードには以下の5種類の命令が存在します。
	?AV         :=: 値比較
	<fV         :=: 相対バックジャンプ
	>fV         :=: 相対フォアードジャンプ
	+A[B|V]     :=: 加算
	-[A|V][B|V] :=: 減算


コメント
------------
以下の構文が存在します。
	_ :=: コメント開始
	= :=: コメント終了


ランドマーク
------------
ランドマーク (記号 ^ ) とは、プログラムにおいてジャンプ先を示す目印命令です。
相対バックジャンプ及び相対フォアードジャンプで使用します。


レジスタクリア
------------
レジスタクリア (記号 # ) とは、指定したレジスタを0にクリアする命令です。
直後にレジスタ名を指定します。空白を挟んではいけません。


整数値入力
------------
整数値入力 (記号 $ ) とは、指定したレジスタに整数値を入力する命令です。
直後にレジスタ名を指定します。空白を挟んではいけません。
入力は標準入力から獲得します。


文字入力
------------
文字入力 (記号 ' ) とは、指定したレジスタに文字を入力する命令です。
直後にレジスタ名を指定します。空白を挟んではいけません。
入力は標準入力から獲得します。入力長さは1文字です。


文字出力
------------
文字出力 (記号 & ) とは、指定したレジスタを文字として出力する命令です。
直後にレジスタ名を指定します。空白を挟んではいけません。
出力先は標準出力です。使用する文字コードは環境に依存します。


インクリメント
------------
インクリメント (記号 / ) とは、指定したレジスタをインクリメントする命令です。
直後にレジスタ名を指定します。空白を挟んではいけません。
インクリメントした結果が0であった場合Cフラグが立ちます。


デクリメント
------------
デクリメント (記号 \ ) とは、指定したレジスタをデクリメントする命令です。
直後にレジスタ名を指定します。空白を挟んではいけません。
デクリメントした結果が255であった場合Cフラグが立ちます。


プッシュ
------------
プッシュ (記号 * ) とは、指定したレジスタの値をスタックにプッシュする命令です。
直後にレジスタ名を指定します。空白を挟んではいけません。


ポップ
------------
ポップ (記号 % ) とは、スタックから指定したレジスタへポップする命令です。
直後にレジスタ名を指定します。空白を挟んではいけません。


値比較
------------
値比較 (記号 ? ) とは、指定したレジスタと与えられた即値について比較をしフラグを立てる命令です。
直後にレジスタ名、即値の順で指定します。空白を挟んではいけません。


相対バックジャンプ
------------
相対バックジャンプ (記号 < ) とは、指定されたフラグステートが真である場合に、即値分のランドマークをスキップした先のランドマークへジャンプする命令です。
ジャンプ方向はバックです。
直後にフラグステート、即値の順で指定します。空白を挟んではいけません。
M1N1で利用可能なフラグステートはZフラグ、Cフラグ、Sフラグ、Aステートのみです。
M1N1ではジャンプ後のフラグリセットは入りません。


相対フォアードジャンプ
------------
相対フォアードジャンプ (記号 > ) とは、指定されたフラグステートが真である場合に、即値分のランドマークをスキップした先のランドマークへジャンプする命令です。
ジャンプ方向はフォアードです。
直後にフラグステート、即値の順で指定します。空白を挟んではいけません。
M1N1で利用可能なフラグステートはZフラグ、Cフラグ、Sフラグ、Aステートのみです。
M1N1ではジャンプ後のフラグリセットは入りません。


加算
------------
加算 (記号 + ) とは、指定したレジスタへ、レジスタ又は即値を加算した結果を保存する命令です。
直後にレジスタ名、レジスタ名又は即値の順で指定します。空白を挟んではいけません。
加算結果がオーバーフローした場合Cフラグが立ちます。


減算
------------
減算 (記号 - ) とは、指定したレジスタへ、レジスタ又は即値を減算した結果を保存する命令です。
直後にレジスタ名又は即値、レジスタ名又は即値の順で指定します。空白を挟んではいけません。
M1N1では即値同士の指定は出来ません。即値を区切る方法が存在しない為です。
減算結果がアンダーフローした場合Cフラグが立ちます。
